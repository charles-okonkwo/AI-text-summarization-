# AI Text Summarizer using Natural Language Processing (NLP)

## Overview

AI Text Summarizer is an Artificial Intelligence web application that uses Natural Language Processing (NLP) techniques to automatically summarize long text documents into shorter and meaningful summaries.

The system analyzes input text, identifies important information, and generates concise summaries while maintaining the main ideas of the original content.

This project demonstrates the use of modern AI models and Transformer-based architectures for solving real-world text processing problems.


## Project Objective

The main objectives of this project are:

- To build an AI-powered text summarization system.
- To apply Natural Language Processing techniques for text analysis.
- To generate accurate and meaningful summaries from large text content.
- To explore Transformer-based models for language understanding.
- To create a simple interface for users to summarize text easily.


## Features

- Input long text documents
- Generate AI-powered summaries
- Extract important information
- Fast text processing
- User-friendly interface
- NLP-based text understanding


## AI Model

The project uses Transformer-based Natural Language Processing models.

Model Workflow:

```
Input Text

     ↓

Text Preprocessing

     ↓

Transformer NLP Model

     ↓

Text Understanding

     ↓

Summary Generation

     ↓

Final Summary Output
```

## Installation

Clone the repository:

```bash
git clone https://github.com/charles-okonkwo/AI-Text-Summarizer.git
```

Navigate into the project folder:

```bash
cd AI-Text-Summarizer
```

Install dependencies:

```bash
pip install -r requirements.txt
```


## Run Application

Start the backend server:

```bash
uvicorn main:app --reload
```

Open the application and enter text to generate summaries.
